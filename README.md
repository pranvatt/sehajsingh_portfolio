# Dr. Sehaj Singh — Medical Portfolio

Static one-page portfolio site (HTML/CSS/JS, no build step needed).

## Files
- `index.html` — page markup
- `styles.css` — all styling (responsive, breakpoint at 800px)
- `script.js` — mobile menu toggle

## ⚠️ Missing asset
`index.html` references `sehaj-singh-portrait.png` (the hero portrait), but no image file was provided, so it's not included in this zip. Add a photo to the project root with that exact filename, or update the `src` in `index.html` to point wherever you place it — otherwise that image will show broken on the live site.

## Deploy
Push as-is to GitHub Pages, Netlify, or Vercel — it's fully static, no dependencies to install.
